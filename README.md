# جسر · Jisr

**Smart studio for translating Arabic Islamic videos into English, with documented Quranic citations.**
منصة ذكية لترجمة الفيديو الإسلامي وتوثيق الاقتباسات القرآنية.

> Built for the AI Challenge for Serving Islamic Content (islamicaich.org), October 2026.
> Jisr is an AI-assisted tool. All Quranic citations are matched against approved sources and must be confirmed by a human reviewer before export.

## The problem
Islamic organizations produce valuable Arabic video content but can't easily reach English speakers. Preparing one video means manual transcription, subtitle timing, translation, and manually looking up every Quranic verse and its approved translation. Verses risk being translated as ordinary speech, and transcription errors in verses can slip through.

## How it works
1. **Upload** an Arabic video
2. **Speech-to-text** with timestamps
3. **Quran detection**: find likely verse quotations in the transcript
4. **Matching** against an approved Quran text database (never generated by AI)
5. **Approved translation** attached to each matched verse; normal speech is machine-translated
6. **Review**: editor confirms/rejects each citation, fixes low-confidence segments
7. **Export**: SRT/VTT subtitles + a shareable citations list

## Run locally
Requirements: Python 3.10+

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements.txt
cp .env.example .env        # then fill in keys
uvicorn backend.app.main:app --reload
```
Open http://localhost:8000

**Frontend only:** open `frontend/index.html` with the VS Code *Live Server* extension (right-click → Open with Live Server). Opening the file directly (`file://`) will not load the data.

In VS Code you can also use **Run and Debug → "Jisr: backend + frontend"**.
