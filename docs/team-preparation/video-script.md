## Recording instructions

- Capture the delivered interface and real output. Avoid the silent illustrative demo for the processing sequence.
- If processing footage is shortened, show “Processing time shortened for demonstration.” If using a previously processed project, label it accordingly.
- Demonstrate an uncertainty only if it actually appears in the selected clip; do not manufacture a failure and describe it as observed behavior.
- Show one readable source record and one readable exported subtitle. Avoid spending the recording on empty screens or repeated navigation.
- Record with a clean browser view. Hide local paths, personal tabs, project edit tokens, and API credentials.
- Keep narration clear and add captions. English narration is drafted here; record in the language you can present most naturally.
- Measure final duration, play the entire file, check text readability and audio, and make sure no unfilled bracketed wording remains.

Suggested working files: submission/video/script.md, raw recordings in submission/video/raw/, and final recording in submission/video/jisr-demo.mp4. Keep licensed or private raw media out of a public repository unless its release is permitted.
